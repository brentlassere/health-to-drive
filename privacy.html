Privacy Policy

Health to Drive · Last updated 9 November 2026

Health to Drive is a personal, single-user script operated by Brent Lassere. This page describes how it handles data obtained through Google APIs.

Who the data belongs to

The only Google account connected to this app is the operator's own account. No other person's data is requested, collected or processed.

What data is accessed

Using the Google Health API with read-only permissions, the script reads the operator's:

  • Activity and fitness data: steps, calories, workout sessions and their metrics
  • Health metrics: heart-rate samples and daily resting heart rate
  • Sleep data: sleep sessions, durations and stages

Using the Google Sheets permission, the script writes that data into a single spreadsheet owned by the operator.

How the data is used

The data is used solely to build a personal daily log in the operator's Google Sheet, for the operator's own review and charting. It is not used for advertising, profiling, research, or any purpose other than displaying it to the operator.

Storage and sharing

  • Data is stored only in the operator's Google Drive (the spreadsheet) and in Google Apps Script's own property storage (OAuth tokens).
  • No data is transferred to any third party, sold, or used to train models.
  • No humans other than the operator can read the data.

Google API Services User Data Policy

Health to Drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the spreadsheet removes all copied data.
